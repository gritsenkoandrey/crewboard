# Task Track

Простой локальный трекер задач для одного человека: проекты, канбан-доска на три колонки,
документация проекта в Markdown и обложка. Работает без интернета и без сервера,
все данные — обычные файлы в выбранной вами папке.

Стек: Tauri 2, React 19, TypeScript, Vite, dnd-kit, CodeMirror, markdown-it.

## Запуск

```bash
npm install
npm run tauri dev
```

## Сборка установщика

```bash
npm run tauri build
```

Установщик появится в `src-tauri/target/release/bundle/nsis/`.

## Где хранятся данные

При первом запуске приложение просит выбрать папку с данными. Лучше выбрать папку не на диске C:
или в облаке (OneDrive, Dropbox) — тогда данные переживут переустановку Windows.
После переустановки достаточно указать ту же папку.

Сама настройка «какая папка выбрана» лежит в `%APPDATA%\com.local.tasktrack\config.json`.

```text
<папка с данными>\
  projects\
    моя-игра\
      project.json         { "name", "createdAt", "cover" }
      README.md            документация проекта
      board.json           { "todo": [...], "inProgress": [...], "done": [...] }
      cover-<время>.png    обложка (копия выбранной картинки)
```

- Имя папки проекта задаётся при создании и не меняется при переименовании.
- Порядок задач в `board.json` совпадает с порядком в колонке.
- Удалённые проекты попадают в корзину Windows.
- В документации можно ссылаться на картинки рядом с README: `![](screens/menu.png)`.

## Структура кода

| Путь | Что там |
|---|---|
| `src-tauri/src/lib.rs` | Настройки, выбор папки данных, регистрация команд |
| `src-tauri/src/projects.rs` | Проекты и обложки |
| `src-tauri/src/board.rs` | Чтение и запись доски |
| `src-tauri/src/docs.rs` | Чтение и запись README проекта |
| `src/App.tsx` | Экран выбора папки, список проектов, страница проекта |
| `src/components/Board.tsx` | Канбан-доска |
| `src/components/Docs.tsx` | Документация: редактор, превью, автосохранение |
| `src/saveTracker.ts` | Дописывает сохранения перед закрытием окна |
